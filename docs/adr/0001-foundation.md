# ADR 0001: переносимая основа и последовательная разработка

Статус: принято.

## Контекст

Проект служит портфолио и средством изучения Go. Доступен один VPS.
Итоговая установка должна быть удобной на Windows, macOS и Linux.

## Решение

Начинаем с одного модуля Go и командного приложения `aegis`. Пакеты внутри
`internal` скрывают реализацию. На первом этапе используем стандартную библиотеку.
Сервер по умолчанию слушает loopback, без публичного административного API.
Проверки HTTP ограничены таймаутом; результат доступен как JSON и код завершения.

CLI и сервер собираются для amd64/arm64 трёх ОС без CGO. Сбор метрик позднее
реализуется переносимыми адаптерами; контейнерные и хостовые метрики различаются.

PostgreSQL добавим вместе с постоянным хранением. Redis вводится только при
обоснованной потребности. Наблюдаемость через Prometheus будет отдельным этапом.

В первой версии дистрибуции — архивы с бинарным файлом и SHA-256, без требования
Go на машине пользователя. Системная служба и установочные пакеты — отдельные
возможности, требующие тестирования на каждой ОС. Подпись Windows и notarization
macOS требуют соответствующих сертификатов; наличие их не предполагается.

## Ограничения

Один VPS позволяет проверить взаимодействие процессов и частичные отказы, но
не независимое обнаружение отказа всей машины. Несколько агентов на одном узле
не считаются испытанием на нескольких физических серверах.

Первая версия не предназначена для публичного приёма недоверенных URL:
проверка произвольного URL является локальной явно вызванной CLI-операцией.
До удалённого управления проверками потребуется модель защиты от SSRF.
