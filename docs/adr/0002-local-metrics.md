# ADR 0002: переносимый сбор локальных метрик

Статус: принято.

Используем gopsutil/v4, чтобы не реализовывать самостоятельно Windows API,
macOS API и чтение /proc. Цена — сторонняя зависимость и различия семантики ОС.
Версия закреплена в go.mod, проверки включают настоящие измерения на трёх ОС.

Потребитель задаёт Source с четырьмя методами; System переводит данные библиотеки
в собственные типы Aegis. Collector управляет конкурентностью и частичными
ошибками, agent.Run — последовательным расписанием и выводом.

Отказ одного источника не скрывает остальные измерения. Сеть пока представлена
счётчиками, а не скоростями, чтобы не придумывать скорость по одному снимку.
CPU измеряется за явное окно, без обращения к неявному предыдущему вызову.

Передача на сервер, долговременное хранение и модель удалённой регистрации
агентов не входят в этот этап. Произвольные системные вызовы не обещают жёсткой
отмены: ждём завершения работников и не допускаем их накопления.
